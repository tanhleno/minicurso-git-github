# Manual particular sobre Git/GitHub

## Conceitos gerais

### O que é Git?

Git é um Software desenvolvido por Linus Torvald para
auxilia-lo no desenvolvimento do Linux.

### O que é GitHub?

GitHub é uma plataforma cujo objetivo principal é armazenar
repositórios Git de maneira remota. Mas também possui outras
funcionalidades, tais quais:

  - Copilot: uma IA do GitHub que ajuda no desenvolvimento.
  Funciona como um grande autocomplete.
  - GitHub Actions: ferramenta de CI/CD do GitHub. Permite
  colocar um código rapidamente em produção a partir de uma
  branch.
  - GitHub Student Pack: uma iniciativa do Git que disponibiliza
  uma serie de programas e facilidades para estudantes.
  - Codespaces: um serviço de máquinas virtuais com VS Code na 
  versão web e ambiente configurável.
  - GitHub Pages: um serviço de hospedagem gratuito para sites
  estáticos.
  - Issures, Projects, Wiki, Pull Request: ferramentas que
  auxiliam no desenvolvimento e manutenção de repositórios remotos.

## Conhecimentos básicos

Qualquer pasta pode ser transformada num repositório.
Basta utilizar o comando `git init`.
