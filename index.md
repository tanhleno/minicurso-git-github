# Minicurso de introdução ao versionamento com Git/GitHub

Este site contém os materiais práticos utilizados no curso 
"Introdução ao versionamento de código com Git/GitHub", realizado
durante a 21ª edição do evento WTADS/WINFO, no IFRN.

Nesse minicurso são abordados conceitos iniciais,
noções básicas de versionamento com Git e boas práticas
para o desenvolvimento colaborativo.
